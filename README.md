# GH-900

Training material for getting started with Git and GitHub (GH-900: GitHub Foundations).

## Contents
- **[InstallGit.md](Instructions/InstallGit.md)**: Instructions for installing and setting up Git on Windows. This guide covers installing Git for Windows and a link to the Visual Studio Code source control quickstart
- **[GitHub.md](Instructions/GitHub.md)**: A step-by-step beginner guide to GitHub. The guide covers creating a GitHub account, creating a new public repository, using GitHub with Visual Studio Code or Windows command line.

Suggested order: start with `InstallGit.md`, then continue with `GitHub.md`.
